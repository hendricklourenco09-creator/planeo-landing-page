# Planéo — landing page (projet de démonstration)

Page de présentation pour **Planéo**, un outil **fictif** de prise de rendez-vous en ligne pour les indépendants.

Projet de démonstration conçu et développé par **Hendrick Lourenco**, développeur web freelance.

## Ce que montre ce projet

- Structure HTML sémantique (header, nav, main, section, article, footer)
- Mise en page en CSS Grid et Flexbox, sans framework
- Design responsive (ordinateur, tablette, téléphone)
- Variables CSS pour les couleurs (thème modifiable en une ligne)
- FAQ dépliable sans JavaScript (`<details>`)
- Validation de formulaire en JavaScript

## Lancer en local

Ouvrir `index.html` dans un navigateur. Aucune installation nécessaire.

## Fichiers

| Fichier | Rôle |
|---|---|
| `index.html` | Le contenu et la structure |
| `style.css` | L'apparence |
| `script.js` | Le comportement du formulaire |
